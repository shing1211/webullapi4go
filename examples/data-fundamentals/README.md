# data-fundamentals

Fetches every fundamentals endpoint for `AAPL` on the US market: company
profile, analyst target and rating, capital flow, industry comparison, earnings
and dividend calendars, SEC filings, income statement, balance sheet, cash
flow, financial indicators, financial alert, and forecast EPS. Read-only.

## Run

```sh
go run ./examples/data-fundamentals
```

## Notes

- Credentials — see [../README.md](../README.md).
- The sandbox serves a limited symbol set (currently `AAPL`).
